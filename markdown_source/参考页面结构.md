# 参考页面结构

下面给你 3 种很简单的个人主页风格，风格都非常轻量，适合你这种简洁、单页、长简历式的个人站。

## 方案 A：纯文字简历式
- 顶部：姓名 + 简短职业方向
- 中间：关于我、经历、项目、能力、联系
- 结尾：GitHub 和简历入口
- 特点：最简单、最稳定、最适合你当前需求

## 方案 B：极简博客式
- 顶部：姓名和一句话介绍
- 中间：多个小段落，每段都很短
- 结尾：作品/链接列表
- 特点：偏个人介绍，不是很像简历，但很舒服

## 方案 C：简洁导航式
- 顶部导航：关于 / 经历 / 项目 / 联系
- 页面内容按章节展开，文字为主
- 每个章节只有 2-4 行文字
- 特点：比较像“个人网站”，但仍然很简约

## 我建议你优先选
- 方案 A：最适合你“简单、顺序、轻量、像长简历”的要求
- 方案 B：如果你想“更像个人介绍页”
- 方案 C：如果你想“更像小型网站导航页”

你现在可以直接选一个，之后我就按照这个结构来改成最终页面。
